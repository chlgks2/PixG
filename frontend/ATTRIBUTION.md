# frontend/ — 제작자 표기

> ## ⚠️ 이 폴더는 **본인이 만든 것이 아닙니다.**
>
> PixG 5인 팀의 **SERVER 파트 팀원이 제작한 UI/UX**입니다.
> 저장소 소유자(최영우)의 담당은 **AI 파트**입니다 — 생성 파이프라인, 후처리, 워크플로우 설계.

## 왜 저장소에 포함했는가

PixG는 "프롬프트를 넣으면 스프라이트 시트가 나오는 **서비스**"로 기획된 프로젝트입니다. AI 파이프라인만 떼어놓으면 **무엇을 위해 만든 파이프라인인지**가 보이지 않습니다. 서비스의 최종 형태를 함께 보여주기 위해 포함했습니다.

## 파트별 담당

| 파트 | 담당 내용 | 이 저장소에서 |
|---|---|---|
| **AI** (저장소 소유자) | Stable Diffusion 생성 파이프라인 · AnimateDiff 전환 · 배경 제거 · 격자 배치 후처리 · 워크플로우 설계 | `workflows/` · `src/` · `assets/` · `docs/` |
| **SERVER** (팀원) | **UI/UX 디자인 및 구현** · 마우스오버·스크롤 화면 효과 · 메인/로딩 영상 | **`frontend/`** ← 이 폴더 |
| Data Science (팀원) | 기획안 · 시장조사 · 현직자 인터뷰 · 생성 보조 | — |

## 구성

HTML · CSS · jQuery로 된 **정적 UI**입니다. 백엔드에 연결돼 있지 않습니다 (`<form action="">`).

```
frontend/
├─ index/PixG.html · download.html
├─ css/  pc.css · mobile.css · download.css
├─ js/   main.js (+ jQuery, slick 등 라이브러리)
└─ images/  스크린샷 · 데모 GIF · 메인 영상
```
